# Universal AI Video Studio — Workflow Rule

1. Always follow: understand -> research -> develop -> write -> review -> approve -> produce -> edit -> verify -> deliver.
2. On initial user idea, ask (1) video type and (2) target duration first before generating a screenplay.
3. Never start expensive video generation without mandatory approvals (`screenplay`, `storyboard`, `production_plan`).
4. Never fabricate research sources, URLs, statistics, or QA pass results.
